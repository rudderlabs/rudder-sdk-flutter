## iOS: CocoaPods only

On iOS, this plugin supports CocoaPods only, not Swift Package Manager (SPM). Flutter 3.44 and later turn SPM on by default, so to use this plugin, turn SPM off in your app's `pubspec.yaml`:

```yaml
flutter:
  config:
    enable-swift-package-manager: false
```

If you have this plugin installed but don't use it, remove it from your dependencies to use SPM.
